# EdenProject

Project Éden Hops represents a technological initiative designed to modernize Brazilian hop cultivation through the principles of Agriculture 4.0. By integrating IoT sensor stations and machine learning, the project aims to replace traditional, reactive farming with predictive modeling and high-resolution environmental monitoring. Ultimately, the project seeks to empower local producers to achieve export-quality yields and reduce dependency on imported agricultural inputs. These advancements ensure a transparent supply chain and more sustainable, data-driven farming practices.

The project is now being developed in different aspects:

1. Develop the hardware/software needed from an automation point of view to ensure the digital transformation of the open field farm.
2. Acquire data from local hop farms in Brazil and other interested countries using the same structure of data collection of the Brazilian project. With the data, use BDA and IA to process the information and compare findings with the Brazilian counterpart.
3. Work on the digitalization aspect of the open farm scenario, proposing methods, architectures and procedures to integrate the farm in the supply chain of Industry 4.0.
